    新图片与空名单如何处理？

    保存自定义名单后，新上传图片需手动勾选。同名覆盖保留原勾选。全部不参与时不自动换图，但仍可深睡和拍醒。

    定时与唤醒

    定时换图时进入深睡省电。参与图片在图片列表中勾选。

    分钟 / 张

    1～10080 分钟；连接电脑时暂停，拔掉后开始计时。

    深睡时的唤醒方式

    默认关闭，与拍击翻页独立；唤醒不刷屏，提供60秒操作窗口。

    连接相框后可设置

    保存启用开关、间隔和唤醒选项，不刷新屏幕。若同时修改了图片勾选，可点「保存定时设置及轮播名单」一起提交。

    深睡、拍醒与关机的区别

    双击只唤醒，不刷屏、不换图，提供60秒操作窗口并重新计算完整间隔；与拍击翻页独立。未开启双击唤醒时，深睡期间需按复位后操作或连接电脑。

    开启双击唤醒会增加 IMU 待机耗电，搬动可能误唤醒。长按电源键关机后，不会自动换图。
